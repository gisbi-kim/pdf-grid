PDF Grid 1.6.2 closes tabs immediately while opening, refreshing or restoring PDFs. Use Cmd+W on macOS, Ctrl+W on Ubuntu, or the × button. Results that arrive after closing a tab are ignored.

- **Apple Silicon Mac** uses the `mac-arm64.dmg` file on macOS 13 or later.
- **Intel Mac** uses the `mac-x64.dmg` file on macOS 13 or later.
- **Ubuntu 24.04 LTS, x86-64** uses the `linux-amd64.deb` file. Run `sudo apt install ./PDF-Grid-1.6.2-linux-amd64.deb` from the download folder.

On Mac, open the disk image and drag PDF Grid to Applications. This build uses an ad hoc signature and has not been notarized by Apple. Check the downloaded file against `SHA256SUMS.txt`. If the first launch is blocked, see [Apple’s instructions for opening an app that hasn’t been notarized](https://support.apple.com/en-us/102445).

Includes PDF tabs, reopening a closed tab, independent side-by-side reading, live PDF refresh, citation previews and session restoration. On Mac, use Command+W, Command+Shift+T and Command+R. On Ubuntu, use Ctrl. Install future releases by downloading the new package. The Windows WebView2 installer is available separately from the [downloads table](https://github.com/gisbi-kim/pdf-grid#설치).
