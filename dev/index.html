브라우저가 열리지만, 보기·합치기·분리하기는 모두 내 PC에서 처리됩니다.

Windows 10/11 · 64비트 · Python·Node 설치 불필요
Windows 앱 다운로드 ↓다운로드 → 설치 파일 실행 → 바탕화면 아이콘설치 없이 쓰는 단일 EXE

이렇게 시작하세요

  1. 설치 파일을 내려받으세요.

    위의 Windows 앱 다운로드 버튼을 누릅니다. 처음 내려받을 때만 인터넷 연결이 필요합니다.

  2. 설치 파일을 한 번 실행하세요.

    필요한 파일이 함께 설치되고, 바탕화면에 PDF Grid 바로가기가 만들어집니다. 설치가 끝나면 기본 브라우저에서 앱이 열립니다.

  3. 다음부터는 바탕화면 아이콘을 누르세요.

    인터넷 연결 없이 PDF를 열고, 합치고, 분리할 수 있습니다. 결과 파일은 PDF 또는 ZIP으로 저장합니다.

브라우저가 열리는데, 왜 로컬 앱인가요?

브라우저는 화면과 파일 처리에 사용됩니다. 앱 실행에 필요한 파일은 컴퓨터에 들어 있고, 화면은 내 PC 주소인 127.0.0.1에서 열립니다. PDF 내용은 외부 서버로 전송되지 않습니다.

설치 없이 쓰고 싶다면

설치 없이 쓰는 단일 EXE를 내려받아 원하는 폴더에 보관하세요. 이 파일을 실행하면 같은 기능을 사용할 수 있습니다. 바탕화면 바로가기는 자동으로 만들지 않습니다.

종료하거나 업데이트하려면

결과 파일을 저장한 뒤 화면 오른쪽 아래의 앱 종료를 누르세요. 새 버전을 쓰려면 실행 중인 앱을 종료하고 최신 설치 파일을 다시 실행하면 됩니다.

지원 환경

Windows 10/11 64비트용입니다. Python이나 Node를 따로 설치할 필요가 없습니다. 현재 배포 파일은 서명되지 않아 Windows에서 게시자 확인 안내가 표시될 수 있습니다.
